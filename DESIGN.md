# LaporKUY interface direction

Use this file for future interface changes. The user requested removing generic AI-template styling, starting with the tiny hero badge, on 22 October 2026.

- Keep the intentional black, white, and gray palette and Plus Jakarta Sans. Use readable text with clear contrast.
- The user explicitly restored the original centered hero, its original title “Kota yang lebih baik, dimulai dari suaramu.” and supporting copy. Keep that hero layout and copy; keep its decorative announcement/BETA badge removed.
- The hero supporting copy has a user-requested typewriter loop inspired by AgentEco: alternate the two existing sentences with typing/deleting, preserve layout height, pause offscreen/in hidden tabs, and show static full copy for reduced motion. This is an explicit exception to avoiding decorative animation.
- Write concrete Indonesian copy about road damage, reports, locations, verification, repairs, and points. Avoid generic aspirational slogans and repetitive sentence fragments.
- Do not add hero announcement pills, decorative BETA badges, all-caps section eyebrows, glowing status dots, filler trust strips, fake avatar stacks, mock browser chrome, or decorative charts.
- Use plain headings and content-led layouts. Do not wrap every feature in an identical icon-topped card. Avoid gradient text, cursor glows, orbit decorations, and entrance animations with no task-related purpose.
- Keep useful status labels, loading/error messages, dates, report metadata, map attribution, privacy explanations, and simulation/illustration disclosures. Small text is acceptable when it conveys necessary information, but must be readable.
- Real reports and their photos are the main visual material. Do not invent testimonials, activity, successful results, or statistics. Label demonstrations clearly.
- Show the Jakarta report map automatically on the landing page, with its markers and filters available without an opening/closing toggle. Device location still requires choosing “Sekitar saya”. The map sidebar is “Laporan terbaru”, sorted by creation time descending; preserve status/title/address and show compact elapsed labels using m, h, d, M, y (uppercase M means month).
- Preserve user-requested interactions: continuous 3D report carousel with equal projected gaps and hover pause, responsive floating navbar, landing anchors, centered authentication modal, interactive map, and voucher redemption. Do not remove these merely because a broad style checklist mentions similar patterns.
- Keep landing sections in navbar order: Fitur, Cara kerja, Laporan, Peta, Dampak, Voucher, FAQ. Logo links go to `/` without a hash. The user has now supplied new morning/day/evening/night backgrounds. Use stabilized normal-speed seamless loops selected by actual Asia/Jakarta time with 12-second smoothstep crossfades around phase boundaries (the source viewpoints differ, so do not leave doubled buildings visible for two hours), fixed framing with the monument as the final tracking anchor and one correction applied to each whole frame. The user specifically requested comfortable, non-warping edges: use only rotation, translation, and uniform scale, with filtered camera estimates and a fixed 4% overscan crop. Do not use per-frame homographies, perspective/mesh deformation, reflected borders, stretch-filled edges, or animated crops. The earlier 0.01-pixel target remains unachieved and must never be claimed as passed based only on one tracked patch. Preserve intact footage: do not segment vehicles, freeze scene regions, or composite static plates, because the user rejected disappearing vehicles, no parallax/zoom/vertical motion, and a dark overlay that preserves sky ambience. Keep scroll blur and monochrome UI. Evening uses the final continuous camera hold (source frames 153–239): exclude the opening backward dolly rather than choosing the longest take or merely locking the statue while the foreground recedes. Its native-speed cycle is 2.875 seconds with a 0.75-second smoothstep tail/head dissolve; do not pretend this is a longer unique take by repeating it in the file. Audit accumulated reference-to-frame architecture AND foreground drift as well as adjacent motion. Never claim every pixel is stationary or 0.01 px precision. Keep native vehicle speed, smooth local monument-tracking noise, and audit left/center/right architecture motion against the accepted night video. Keep that night asset unchanged while tuning evening.

These are project decisions, not a claim that a font, dark theme, or card can prove AI authorship.
